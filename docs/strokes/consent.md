# Consent: racquet sensor study

Read this to the participant (or hand it over) **before** the first recording. Record the name and the date in
`~/Datasets/oso-strokes/private/participants.csv` (name, ID, consent date), never in this repo and never in the data folders.

**What we record.** A small motion sensor in a pod on your racquet records how the racquet moves (rotation and acceleration, 500
times a second) while you hit the shots you are asked to hit. Optionally, a phone on a tripod films you from the side so we can
check what each swing was. Filming is optional: say no and we only use the sensor.

**What it is for.** Teaching a program to recognise badminton strokes (clear, smash, drop and so on) from the sensor alone, so
that players can get a report after a match.

**Your name stays out of the data.** The data carries a code such as `P07` only, plus your handedness, level (beginner, club or
advanced) and height range. The list that links the code to your name is kept separately, on one computer, and is never shared.

**Where it lives.** On the researcher's own computer. The motion data and any video are not uploaded or published. The trained
model that comes out of it contains no recordings, and it may be shared with the app and the website.

**Your rights.**
- You can stop at any time.
- You can withdraw later: tell the researcher your code or name, and your recordings, labels and video are deleted and the
  data is rebuilt without you. A model that was already trained is replaced at the next version.
- Video can be deleted after labelling if you prefer, and the sensor data can stay.
- Publishing the recordings themselves would need a separate, new consent from you.

**Risks.** The same as ordinary badminton practice. You choose your own pace and can rest whenever you like.
